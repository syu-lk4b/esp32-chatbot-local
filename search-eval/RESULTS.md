# 联网搜索方案对比（2026-10-23，上海家庭网络，经特殊路由出口）

测试：6 类问题（天气 / 股价 / 科技新闻 / 近期事实 / 产品价格 / 本地生活），每个方案单独请求。
「相关」= 经 `rank_results`（与问题的词重叠 ≥30%）过滤后仍有结果。脚本：`eval_search.py`，原始数据 `results.json`。

## 通用搜索（经本地 SearXNG，单引擎）

| 引擎 | 可用 | 有相关结果 | 中位耗时 | 观察 |
|---|---|---|---|---|
| Bing | 6/6 | 4/6 | 0.4 s | 最快；股价、诺奖这类问题常返回无关英文页 |
| Bing 新闻 | 5/6 | 4/6 | 0.45 s | 新闻时效好；偶发 parsing error |
| Yandex | 6/6 | 6/6 | 0.7 s | 中文结果意外不错，偶有无关娱乐站 |

## 结论

1. 通用搜索引擎改为 **Bing + Yandex + Yahoo（网页）+ Bing 新闻 + DuckDuckGo 新闻**，去掉当前网络下不可用的引擎，减少等待超时。
2. 高频问题走专用工具：**天气 → Open-Meteo，股价 → 腾讯行情，科技新闻 → RSS**。数据准确，一次调用即可回答，不再依赖网页摘要拼凑数字。
