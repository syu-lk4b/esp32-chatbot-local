# Configuration

## Server: `server/.env`

Generated by `install.sh` (mode 600, gitignored); template in `server/.env.example`. Run `./start.sh` again after editing to apply.

| Variable | Default | Meaning |
|---|---|---|
| `VOICE_TOKEN` | random at install | the board's `X-Token` header must match (firmware `CHAT_TOKEN`). The server refuses to start with an empty token unless bound to loopback |
| `VOICE_HOST` / `VOICE_PORT` | `0.0.0.0` / `8765` | must be reachable on the LAN for the board |
| `LLM_BACKEND` | `openai` | `openai`: LM Studio or any OpenAI-compatible server; `ollama`: Ollama's native API |
| `LLM_URL` | `http://127.0.0.1:1234/v1` | `http://127.0.0.1:11434` for Ollama |
| `LLM_MODEL` | `qwen3-30b-a3b-instruct-2507` | the model id as the server reports it (LM Studio: `curl $LLM_URL/models`) |
| `LLM_REASONING_EFFORT` | empty | `none` turns thinking off for reasoning models (2–3× faster replies) |
| `LLM_MAX_TOKENS` | `600` | per-reply cap (thinking tokens count too) |
| `USER_LOCATION` | `上海` (Shanghai) | default location for weather, news, and the clock/weather card |
| `SYSTEM_PROMPT` | see `voice_server/config.py` | may use the `{location}` placeholder |
| `WHISPER_MODEL` | `mlx-community/whisper-large-v3-turbo` | any mlx-whisper model |
| `TTS_ENGINE` | `qwen3` | `qwen3`: natural, emotion-aware (~1 s per sentence); `piper`: fast (download a voice with `piper.download_voices`) |
| `QWEN_TTS_MODEL` / `QWEN_TTS_VOICE` | `…Qwen3-TTS-12Hz-1.7B-CustomVoice-6bit` / `vivian` | voices: serena, vivian, uncle_fu, ryan, aiden, ono_anna, sohee, eric, dylan |
| `PIPER_VOICE` | `server/models/zh_CN-huayan-medium.onnx` | Piper voice path |
| `SEARXNG_URL` | `http://127.0.0.1:8888` | local SearXNG |
| `DEBUG_CLIPS_DIR` | `server/debug_clips` | recordings that transcribed to nothing are saved here; empty disables it |

### Choosing an LLM

A **fast MoE model** is recommended (e.g. Qwen3-30B-A3B Instruct: only ~3B parameters active per token, ~0.3 s for small talk). Dense models (e.g. 27B) give richer answers but are several times slower; for a thinking model set `LLM_REASONING_EFFORT=none`. The model must support tool (function) calling.

### English replies

The default system prompt makes XiaoQi answer in Chinese. To get English answers, set `SYSTEM_PROMPT` (keep the emotion-tag instruction from the default in `voice_server/config.py`) and pick an English voice such as `QWEN_TTS_VOICE=ryan`. The wake word stays "小奇小奇".

### Web tools

| Tool | Source | Use |
|---|---|---|
| `get_weather` | Open-Meteo (no key) | current weather + 1–7 day forecast |
| `get_stock_quote` | Tencent quotes (no key) | A-shares / HK / US stocks, indices, ETFs, by name or code |
| `get_tech_news` | IT之家 (ITHome) and 少数派 (sspai) RSS | tech news, prefetched every 5 min |
| `web_search` | local SearXNG | everything else that needs live data |

SearXNG's engines are set in `searxng/settings.template.yml` (copied at install time to `settings.yml` with a random secret). Defaults are Bing / Yandex / Yahoo / Bing News / DuckDuckGo News, a set measured to work on a home network in mainland China. On a different network, re-evaluate with `search-eval/eval_search.py`.

## Firmware: `firmware/include/secrets.h`

Generated by `install.sh` (gitignored); template `secrets.example.h`:

| Macro | Meaning |
|---|---|
| `WIFI_SSID` / `WIFI_PASS` | 2.4 GHz Wi-Fi |
| `CHAT_SERVER` | `http://<Mac LAN IP>:8765` |
| `CHAT_TOKEN` | = `VOICE_TOKEN` in `server/.env` |

Add `-DTZ_INFO=\"<POSIX TZ>\"` to `build_flags` in `firmware/platformio.ini` to change the clock's time zone (default `CST-8`, Beijing time). The city on the weather card is the server's `USER_LOCATION`.

Constants at the top of `firmware/src/main.cpp`:

| Constant | Default | Meaning |
|---|---|---|
| `FOLLOW_UP_MS` | 8000 | AUTO mode window for follow-ups without the wake word |
| `MAX_RECORD_SECONDS` | 15 | longest single utterance |
| `ECHO_HOLDOFF_MS` | 350 | mic ignored after playback so it doesn't hear itself |
| `SLEEPY_AFTER_MS` | 60000 | idle time before XiaoQi gets sleepy |
| `EMOTION_HOLD_MS` | 4000 | how long the emotion face stays after speaking |
| `WEATHER_REFRESH_MS` | 900000 | clock/weather card refresh interval (15 min) |

AUTO-mode voice detection thresholds are in `firmware/include/vad.h` (`START_FLOOR` / `KEEP_FLOOR` etc.); use the serial `v` command to see actual levels before tuning.

## Serial commands

Watch the log with `python3 tools/mon.py 30`, or any serial terminal at 115200, and send a single character:

| Command | Action |
|---|---|
| `t` | send a 1 s test tone through the full pipeline |
| `s` | ask for a ~100-character story via `/api/chat_text` (tests multi-sentence playback without speaking) |
| `m` | toggle HOLD / AUTO |
| `k` | switch skin |
| `v` | toggle VAD level / threshold printing |
| `b` | print battery voltage, percentage, charging state |
| `w` | scan and list the access points broadcasting the configured SSID |
| `c` | screenshot (used by `tools/snap.py`) |

Note: on the ESP32-S3's native USB, opening the serial port resets the chip; wait for boot (~8–10 s, `snap.py --wait 10`) before sending commands.
